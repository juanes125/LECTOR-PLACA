# Acuerdo de colaboración del equipo

## Roles
| Integrante | Rol | Responsabilidades |
|---|---|---|
| [Nombre 1] | **Coordinador del repositorio** | Es dueño del repo en GitHub, agrega a los demás, revisa y aprueba los Pull Requests, mantiene el README y entrega el trabajo. |
| [Nombre 2] | **Desarrollador** | Escribe y modifica `lector_placas.py` en ramas propias, hace commits con mensaje claro y abre Pull Requests. |
| [Nombre 3] | **Revisor y pruebas** | Prueba el programa con la cámara, revisa los Pull Requests antes de aprobarlos, documenta casos de prueba y evidencias. |

*Los roles rotan en cada entrega para que todos conozcan todo el proyecto.*

## Reglas de trabajo
1. Nadie sube cambios directo a `main`: cada cambio va en una rama (`feature/...`, `fix/...`) y un Pull Request.
2. Todo Pull Request lo revisa al menos otro integrante antes de unirse.
3. Mensajes de commit claros, en presente, explicando qué y por qué (ej. `Corrige PermissionError al guardar registro.csv`).
4. Antes de subir, probar que el programa abre y lee una placa.
5. No subir fotos de placas reales ni la carpeta `Placas_Guardadas/`.
6. Si se usa IA, se anota en el commit o PR y el equipo revisa y entiende el código.
